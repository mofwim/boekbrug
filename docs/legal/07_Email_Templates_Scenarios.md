# 📋 Internal Procedures (For Yourself)

## Procedure A: Receive Belastingdienst request

```
ZODRA EEN VERZOEK BINNENKOMT:

Dag 1:
□ Print/save het verzoek
□ Verifieer authenticiteit (officiële brief, niet email)
□ Email auto-acknowledgment binnen 24 uur
□ Log in audit_logs
□ Contact ICTRecht (€100-300 consultation)

Dag 2-3:
□ Receive legal opinion
□ Determine scope (welke data exact?)
□ Determine method (CSV, PDF, official format?)
□ Inform affected user (per Art. 14 AVG)

Dag 4-10:
□ Prepare data export
□ Quality check (privacy of others?)
□ Cover letter met legal references

Dag 11-14:
□ Send data via official channel
□ Get confirmation of receipt
□ Archive everything
□ Update audit logs
```

## Procedure B: Data breach response

```
ZODRA BREACH GEDETECTEERD:

Eerste uur:
□ Block compromised access
□ Document timestamp
□ Take screenshots of relevant logs

Eerste 4 uur:
□ Determine scope (1 user vs 1000)
□ Determine type of data
□ Determine method (hack, leak, internal)
□ Patch the issue

Eerste 24 uur:
□ Forensic analysis complete
□ Affected users list ready
□ Draft AP notification

24-48 uur:
□ AP notification submitted via:
   https://datalekken.autoriteitpersoonsgegevens.nl
□ Email affected users (Template 4)
□ Update status page

48-72 uur:
□ Follow-up with AP if needed
□ Continue monitoring
□ Public statement if necessary
```

## Procedure C: User account recovery

```
WANNEER USER VRAAGT ACCOUNT TERUG:

Step 1: Verificatie
□ Email van bekend adres? → Easy reset
□ Email van NIEUW adres? → Strict verification

Step 2: Strict verification (voor nieuwe email)
□ Vraag minimaal 5 verificatie-items
□ Match tegen DB
□ Vereist tenminste 4/5 match
□ Bij twijfel: REJECT

Step 3: Manual review (admin)
□ Review verzoek + verification data
□ Approve only if confident
□ Document beslissing in audit logs

Step 4: Execute recovery
□ Update email in DB
□ Force password reset
□ Email tijdelijk wachtwoord
□ Forceer 2FA setup
□ Audit log alle stappen
```

# 🎯 Sleutelregels (Memoriseer dit)

```
1. ALTIJD ANSWERS WITHIN 24 HOURS
   (zelfs als alleen "we received your request")

2. NEVER GIVE DATA ZONDER VERIFICATION
   (overheid moet zich identificeren)

3. INFORMEER USER OF DATA SHARING
   (per AVG Art. 14, behalve uitzonderingen)

4. KEEP AUDIT LOGS VOOR ALLES
   (deze save je leven later)

5. DOCUMENT EVERY DECISION
   (waarom heb je wel/niet geleverd?)

6. INVOICE/BTW DATA = 7 JAAR BEWAREN
   (nooit verwijderen, behalve na 7 jaar)

7. AUDIT LOGS = OOK 7 JAAR
   (compliance verplicht)

8. AT FIRST SIGN OF PROBLEM:
   - Calm down
   - Document timeline
   - Contact legal advisor
   - Don't panic-respond
```
